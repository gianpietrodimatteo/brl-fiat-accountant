# Epic 1: Project Setup & Tooling

## Goal
Establish the foundational project structure, tooling, and standards that all subsequent work builds on.

## Scope
- Repository structure (backend/frontend layout)
- TypeScript configuration for backend and frontend
- Docker Compose setup (SQLite persistence, app services)
- Linting/formatting standards (ESLint, Prettier or equivalent)
- `CLAUDE.md` (project context for AI-assisted work)
- `.claude/settings.json`
- `.claude/rules/` (business, backend, frontend rule sets)
- Package manager and dependency baseline
- `business/epics` and `business/tickets` structure (this document itself)

## Out of scope
- Any business logic, API endpoints, or UI screens
- CI/CD pipelines (not required by the challenge)

## Dependencies
None. This is the first epic.

## Tickets
See `business/tickets/` for tickets numbered under this epic.
