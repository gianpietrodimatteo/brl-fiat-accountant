This application provides exchange rate quote: the authenticated customer selects a target currency and specifies the
number of units to purchase, and the system calculates the cost in Brazilian Reais (BRL) using USDT as a bridge
currency. The quote has an expiration time and, if confirmed, is recorded in the customer's history.
