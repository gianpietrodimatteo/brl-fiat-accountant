# Definition of Done

- [ ] Every item in the ticket's `Acceptance Criteria` is individually verified (tested/built/run), not just assumed
- [ ] Nothing from the ticket's `Out of scope` was implemented
- [ ] Code follows existing conventions in the touched folder (`backend/` or `frontend/`), including `.claude/rules/`
- [ ] New or changed logic has tests per `.claude/rules/testing.md` — a feature without tests is not done
- [ ] Lint, build, and tests pass for every touched folder (`backend/`, `frontend/`, `e2e/`)
- [ ] No changes made to `DECISIONS.md`
- [ ] Any ambiguity was raised with the user instead of silently assumed
