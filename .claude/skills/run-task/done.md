# Definition of Done

- [ ] Every item in the ticket's `Acceptance Criteria` is individually verified (tested/built/run), not just assumed
- [ ] Nothing from the ticket's `Out of scope` was implemented
- [ ] Code follows existing conventions in the touched folder (`backend/` or `frontend/`)
- [ ] Lint/build/tests pass for the touched folder, if configured
- [ ] No changes made to `DECISIONS.md`
- [ ] Any ambiguity was raised with the user instead of silently assumed
